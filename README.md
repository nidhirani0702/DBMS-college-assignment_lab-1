#  SQL DDL & DML Practice – CollegeDB

This repository contains a complete **SQL script** covering **DDL (Data Definition Language)** and **DML (Data Manipulation Language)** operations as part of database practice questions.

The script is written in a **single structured flow** starting from table creation to data manipulation and deletion.

---

##  Topics Covered

###  DDL (Data Definition Language)
- Create database and tables
- Alter table (add column, rename column)
- Drop table

###  DML (Data Manipulation Language)
- Insert records
- Retrieve data using SELECT
- Update existing records
- Delete specific and all records

##  SQL Script Details

The SQL file includes solutions from **Question 3 to Question 18**, covering:

###  DDL Operations
- Creating `Student` and `Course` tables
- Adding new columns (`City`, `Semester`)

###  DML Operations
- Inserting 5 student records
- Displaying full and partial records
